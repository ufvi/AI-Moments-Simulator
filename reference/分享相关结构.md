## Firebase 数据路径

| 路径            | 内容                  | 格式                     |
| --------------- | --------------------- | ------------------------ |
| `{ns}/posts`    | 所有帖子              | 数组或对象，按 `id` 查找 |
| `{ns}/accounts` | 所有账号（普通 + AI） | 数组或对象               |

**注意**：posts 和 accounts 可能是数组也可能是对象（Firebase 特性），用 `Array.isArray(x) ? x : Object.values(x)` 兼容。

并行拉取：
```js
const [postsSnap, accountsSnap] = await Promise.all([
  get(dbRef("posts")),
  get(dbRef("accounts")),
]);
// 建立查找 Map
const accountsMap = {};
accounts.forEach(acc => { if (acc?.id) accountsMap[acc.id] = acc; });
```

## 帖子数据结构

```js
{
  id: "post_1712345678901",          // 唯一 ID，分享页通过 ?id=xxx 传入
  userId: "acc_1712345678",          // 发帖人账号 ID，去 accountsMap 查
  text: "支持 **Markdown** 的正文",   // Markdown 格式
  images: ["media_1712345678_a1b2c3"],  // 图片媒体 ID 数组
  videos: [],                           // 视频媒体 ID 数组
  likes: ["acc_1712345680"],            // 点赞用户 ID 数组
  comments: [ /* 见下方评论结构 */ ],    // 内嵌评论（可选）
  timestamp: 1712345678901,             // 毫秒时间戳
  pinned: false,                        // 是否置顶

  // === 以下为代写功能（ghost writer），可选 ===
  ghostWriter: "acc_ai_1712345679",     // 代写的 AI 账号 ID
  ghostInput: "今天堵车两小时..."        // 用户的原始输入
}
```

### 媒体 URL

API：`/api/media/{ns}/{mediaId}` 需整体编码为单个路径段

```js
// 正确写法
function mediaUrl(mediaId) {
  const base = "";  // 可为 Worker 地址，空串则用当前 origin
  return `${base}/api/media/${encodeURIComponent(ns + "/" + mediaId)}`;
}
```

## Markdown 解析

使用本地文件，按顺序引入：

```html
<script src="marked.umd.js"></script>
<script src="markdown.js"></script>
```

引入后 `window.marked` 和 `window.App.parseMarkdown` 可用。直接调用：

```js
const html = window.App.parseMarkdown(text);  // 返回 HTML
```

包含的特性（定义在 `markdown.js`）：
- GFM 标准（表格、任务列表、删除线等）
- 剧透语法 `||文字||`
- 安全 URL 校验（不安全链接只显示为纯文本）
- KaTeX 数学公式（`$...$` 行内，`$$...$$` 块级）
- 代码块复制按钮

- 帖子正文容器类名：`.post-text`
- 评论正文容器类名：`.comment-content`
- 样式由根目录 `styles.css` 统一提供（代码高亮、表格、列表、剧透 `||` 等）

## 代写功能（Ghost Writer）

当 `post.ghostWriter` 存在时，显示代笔标签：

```html
<div class="ghost-tag">✍️ AI名代笔</div>
```

点击弹出弹窗，显示：
- `由 <b>AI名</b> 代写`
- 用户原始输入 `post.ghostInput`

AI 账号信息：`accountsMap[post.ghostWriter]`

## 媒体渲染

`post.images[]` 和 `post.videos[]` 都是媒体 ID 数组，通过 `mediaUrl(id)` 转为图片/视频 URL。

图片最多显示前 4 张，视频全部显示（带 `controls`）。布局网格：
- 1 张：单列，自适应比例，最大高度 400px
- 2 张：两列
- 3 张：三列
- 4 张：两行两列

图片点开灯箱查看，视频点开播放器播放。
